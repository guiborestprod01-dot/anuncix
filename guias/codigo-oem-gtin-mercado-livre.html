Código OEM, número de peça e código de barras: qual vai onde

São três códigos diferentes, e colocar um no lugar do outro faz o anúncio sumir de quem busca pelo código certo.

Cada código tem uma função

  • Código OEM: o número da peça original da montadora. É o que o mecânico procura.
  • Número de peça (part number): o código do fabricante da peça que você vende (Cofap, Bosch, Nakata…).
  • Código de barras (GTIN/EAN): os 8, 12, 13 ou 14 dígitos impressos embaixo das barras da embalagem.

O erro mais comum

Colar o código de barras no campo de OEM. Um número de 13 dígitos começando com 789 é quase sempre um EAN brasileiro, não um código da montadora.

AntesOEM: 7891234567895 · Código de barras: vazio
DepoisOEM: 5U0 413 031 · Número de peça: HG 1234 · Código de barras: 7891234567895

Por que vale a pena acertar

Quem busca pelo código OEM está pronto para comprar: sabe exatamente qual peça precisa. Se o seu anúncio não tem o código no campo certo, essa venda vai para outro vendedor.

Atalho

O raio-x do Anuncix avisa quando um código OEM parece código de barras e quando um anúncio de peça está sem número de peça. Na correção automática, o código de barras encontrado no campo errado é movido para o campo certo; códigos OEM e de peça nunca são inventados.
